# OSS CAD Suite for Linux x86_64

This directory contains the [OSS CAD Suite 2026-07-27 Linux x64 archive](https://github.com/YosysHQ/oss-cad-suite-build/releases/tag/2026-07-27) split into 48 MiB files. `make formal-doctor` or `make gui` verifies the combined archive against `SHA256SUMS` and extracts it under `formal_runtime/linux-x64/`.

The archive includes the license notices in `oss-cad-suite/license/`. The [upstream build sources](https://github.com/YosysHQ/oss-cad-suite-build/tree/2026-07-27) identify the source projects and revisions for the distributed tools.
