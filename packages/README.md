# 开发用源码包

此目录的 ZIP 和 tar.gz 为开发用源码包。Linux x64 使用 `formal-portable` 分支的 **Code → Download ZIP** 或 Release 的完整包。两个入口都包含 Python、Tk 和开源 Formal。[完整 ZIP](https://github.com/ysyx-22040210-yudian/CMDBUF-Studio/archive/refs/heads/formal-portable.zip) · [Release 完整包](https://github.com/ysyx-22040210-yudian/CMDBUF-Studio/releases/latest/download/cmdbuf-studio-linux-x64.tar.gz)

解压后进入包含 `Makefile` 的目录，运行 `make formal-doctor` 自检并用 `make gui` 启动。
