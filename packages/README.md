# 开发用源码包

此目录的 ZIP 和 tar.gz 包含工程源码。Linux 目标机使用 [最新版 Release](https://github.com/ysyx-22040210-yudian/CMDBUF-Studio/releases/latest) 中的架构包。

- [Intel / AMD 64 位（x86_64）](https://github.com/ysyx-22040210-yudian/CMDBUF-Studio/releases/latest/download/cmdbuf-studio-linux-x64.tar.gz)
- [ARM64（aarch64）](https://github.com/ysyx-22040210-yudian/CMDBUF-Studio/releases/latest/download/cmdbuf-studio-linux-arm64.tar.gz)

以上两个 Linux 完整包自带 Python、Tk 和开源 Formal。解压后进入 cmdbuf-studio，运行 make formal-doctor 自检，再运行 make gui。
